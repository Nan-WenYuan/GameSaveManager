# 游戏存档管理器

本项目基于 [mcthesw/game-save-manager](https://github.com/mcthesw/game-save-manager) 修改，面向个人游戏存档备份与恢复。它是 Nan-WenYuan 维护的自用版本，不是原项目的官方发布；感谢原作者 Sworld 及所有贡献者。

## 自用版修改（2026-10-02）

- 以本地备份为主，云端上传与拉取由用户手动操作；拉取备份与恢复游戏存档分开。
- 首次手动上传会自动登记该游戏，无需先启用云备份；日常本地操作不触发云端传输。
- 云备份显示完整本地与云端数量，支持全部游戏、单个游戏、单份备份的上传与拉取；已有副本仍可重新传输，覆盖前确认方向和数量。
- 云备份页支持手动上传、拉取游戏管理配置：只同步游戏列表、存档位置及备份设置，不上传令牌、本地备份目录或界面设置。拉取前确认覆盖并备份本机配置，已有游戏保留本机路径；新游戏的存档位置请检查后再使用。
- 精简首页、设置与导航中的多设备管理等入口，高级视图和设置默认折叠，保留恢复确认、恢复前保护备份及完整性检查。
- 游戏列表显示实际存在的本地备份数量与最近备份时间；游戏页显示完整备份目录并支持打开目录。
- 便携数据集中存放在 `data`，配置目录使用 `GameSaveManager.config`；备份位置可自定义，新配置默认 `backups`，保留已有目录设置和旧 ZIP 备份读取能力。
- 程序统一命名为“游戏存档管理器”，包内文件名固定为 `游戏存档管理器.exe`；交付文件夹带语义版本、北京时间打包批次及类型，默认不压缩。
- “应用前删除”改为“恢复前清空原存档”，明确恢复操作含义。
- 桌面程序只运行一个实例；再次打开时唤起已有窗口，支持从最小化状态恢复。

## 源码与更新

本公有仓库的 `main` 分支提供程序源码，版本标签与 Releases 对应。当前源码版本：**1.12.4**。

个人游戏存档、配置和凭据保存在本地或个人私有仓库，不包含在本仓库。程序更新从本仓库 Releases 匿名下载。

开发环境：Rust、Node.js 与 pnpm。安装 Tauri 平台依赖后运行 `pnpm install`，使用 `pnpm dev` 开发、`pnpm build` 构建；详细开发和构建说明见 [AGENTS.md](AGENTS.md)。

每次正式发布同步对应源码，保留许可证和原作者声明；Release 附件同时提供完整源码 ZIP。

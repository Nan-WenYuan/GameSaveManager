# 游戏存档管理器

这是 Nan-WenYuan 维护的个人修改版程序发布仓库，基于 [mcthesw/game-save-manager](https://github.com/mcthesw/game-save-manager)。不是原项目官方发布。感谢原作者 Sworld 及所有贡献者。

请在 [Releases](https://github.com/Nan-WenYuan/GameSaveManager-Releases/releases) 下载程序。程序可以匿名检查和下载更新，无需 GitHub Token。配置与游戏备份保存在本地；游戏存档上传、拉取继续使用个人私有仓库和授权 Token。此公有仓库不包含个人游戏存档、访问令牌或私有仓库历史。

主要修改：本地备份优先、便携数据目录、简化界面、手动按游戏或备份上传与拉取、单实例运行及程序自动更新。
